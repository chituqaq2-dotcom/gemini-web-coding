# 写给 Codex（本地 agent）的指令模板

中文，用户直接粘进 Codex。按需删减。

```
仓库 <Windows 路径>，分支 <分支>（<提交号>）。<一两句背景/问题>。

请一口气做完，小问题自己修、事后汇报，只在需要我登录/输密码、合并有冲突、或要重启 runabout 时停：

1. <查原因/改动>
2. Node 用 D:\Program Files\DevTools\nodejs（放 PATH 最前，不改 nvm 全局），先 . .\scripts\use-test-drive.ps1，跑 <相关测试> 确认全绿。
3. <提交到本分支 / 部署 / 起开发服务并自己打开页面验证>
4. 不要 push、不要合并、不要删东西（要删的挪到 D:\Projects\_trash\<名字>-<日期>，写 MANIFEST）。保持 CRLF。

汇报：原因、改了什么、提交号、测试结果、我该打开/操作什么。不要写出域名、密钥、坐标。
```

清理类先发只读盘点：

```
仓库 <路径>。只读盘点，不改、不提交、不挪、不删：
<逐项列出要查的目录/worktree>，每条给：路径、分支、最后修改时间、改动文件数、改动内容一句话、是否已进主线、未推送提交数、大小、建议（丢弃/保留/需要我看）。
一张表，每行带编号方便我勾选。
```

用户勾完再发：“编号 X、Y 移到回收目录 D:\Projects\_trash\<名字>-<日期>，保留相对路径，写 MANIFEST；移动前复核状态，有变化就跳过并报告；worktree 移完 git worktree prune，分支不删；对比 git status 前后。”
