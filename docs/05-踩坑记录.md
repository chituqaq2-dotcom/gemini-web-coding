# 05 踩坑记录

按遇到的顺序记。

### 1. `wsl --update` 不存在 / 只打印帮助
**现象**：新电脑运行 `wsl --update` 退出码 1，帮助里只有 --install / --list / --status。
**原因**：没装真正的 WSL，只有系统自带的 wsl.exe 空壳。
**解决**（管理员 PowerShell）：
```powershell
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
wsl.exe --install --no-distribution   # 不支持就 winget install --id Microsoft.WSL -e
```
DISM 返回 3010 = 需要重启。重启后 `wsl --version` 确认。

### 2. 本地 agent 动不动就停
**原因**：提示词写了“报错就停，不要自己换方案”。
**解决**：改成“小问题自己最小化修复并事后汇报，只在 重启 / 密码 / token / 删除覆盖数据 / 额外挂载 时停”。

### 3. 重启后 agent 会话断了
Codex CLI：同目录管理员 PowerShell 运行 `codex resume --last`，再发“继续”。接不回来就重贴部署提示词并说明进度。

### 4. Ubuntu 下载中断
官方源中断时改用国内镜像（如中科大），**安装前核对 SHA-256**。

### 5. 首次进 WSL 默认用户名是 administrator
第一次 `wsl -d Ubuntu-24.04` 会让你建用户，提示的默认名就是 Windows 用户名，删掉改成你想要的。这个 Linux 密码和 runabout 登录密码是两回事，建议不同。

### 6. “检测到 localhost 代理配置，但未镜像到 WSL”
`.wslconfig` 加 `networkingMode=mirrored`，`wsl --shutdown`。之后 GitHub、Docker 镜像都能走 Windows 代理。

### 7. agent 要 sudo 密码
别给。让它用 `wsl -d Ubuntu-24.04 -u root -- <命令>` 从 PowerShell 跑 root 命令。

### 8. 项目在 D 盘，Windows 弹窗提示跨文件系统 git 慢
点“不再显示”。放 D 盘是为了让 Windows 上的工具也能用同一份文件，普通项目感觉不到慢。特别大的仓库卡了再单独搬进 WSL。

### 9. Docker 构建下载超时 / 502
构建时走本机代理，Debian 源换国内镜像。本地复制一份 `Dockerfile.local` 改源；**以后 git pull 更新时先 `diff -u Dockerfile Dockerfile.local`**，上游改了构建步骤要同步。

### 10. 域名返回 530
隧道没连上：token 没填 / 没生效，或 cloudflared 容器没起来。

### 11. 隧道 502
Public hostname 的 Service 写成了 `http://127.0.0.1:8484`。要写容器名 `http://runabout:8484`，且两个容器在同一个 docker 网络。

### 12. Gemini 说“不是有效的 MCP 服务器”
没开 `auth.allow_unauthenticated_initialize: true`。Gemini 第一次握手不带认证。开了不会放开工具权限（未登录的 tools 调用仍是 401）。

### 13. smoke.sh 15/17
那 2 项失败是脚本预期匿名 initialize 返回 401，和第 12 条的开关冲突，正常。

### 14. 设置里找不到 Connected Apps
在 **Personal Intelligence** 里面；或直接打开 `gemini.google.com/customize/connectors`。

### 15. 添加时要填 Client ID / secret 吗
不用，留空。runabout 支持动态客户端注册。

### 16. 忘了把应用改成英文名
没有重命名按钮，Disconnect 后重加。旧授权留在服务端不碍事。

### 17. 不加 @ 它不调工具
提示词里带 `@runabout` 强制调用。

### 18. 交接文件放哪
不是 `/workspace` 总根目录，而是**每个项目自己的文件夹**，和它的 README 放一起。项目已有 AGENTS.md / docs 体系就直接用，不必再建 NOTES.md。

### 19. 大项目统计磁盘很慢
挂载的是 Windows 盘（经 WSL 跨文件系统），8 万个文件 `du` 很慢。让 Gemini 后台跑、跑完再读。
