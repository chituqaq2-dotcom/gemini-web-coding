# 06 维护

进 WSL：`wsl -d Ubuntu-24.04 -u <你的Linux用户>`，然后 `cd ~/runabout/deploy`。

| 操作 | 命令 |
|---|---|
| 看状态 | `docker compose ps` |
| 重启服务和隧道 | `docker compose restart` |
| 看日志 | `docker compose logs --tail=100 -f mcp cloudflared` |
| 公网健康 | `curl -fsS https://mcp.你的域名/healthz` |
| 更新源码 | `git pull --ff-only` |
| 更新并重新部署 | `docker compose pull cloudflared && docker compose up -d --build` |

更新前如果用了 `Dockerfile.local`：`diff -u Dockerfile Dockerfile.local`，上游改了构建步骤先同步。

## 加挂载
需要让 Gemini 看到项目目录以外的东西（比如工具配置），在 override 里加一行**只读**挂载：`/mnt/e/xxx:/tools/xxx:ro`，然后 `docker compose up -d`。容器是 Linux，Windows 的 .exe 跑不了。
